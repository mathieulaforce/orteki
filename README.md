# orteki

Offline dictation and rewrite with recipes for KDE Plasma on Wayland. *orteki* comes from West Flemish *ort ekier*, "listen".

Work in progress: see the [spec](https://github.com/mathieulaforce/orteki/issues/1).

## Install

```bash
uv tool install git+https://github.com/mathieulaforce/orteki          # CLI only
uv tool install "orteki[gui] @ git+https://github.com/mathieulaforce/orteki"  # with the Qt app
```
